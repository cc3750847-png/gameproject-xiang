## 当前原型关注点

- 先验证主线中枢是否成立，而不是追求最终视觉细节
- 保证“扫一扫 / 引导 / 到点 / 共鸣 / 进入节点游戏 / 返回主线”这条链路顺滑
- 页面结构要为后续统一 UI 风格留足空间
- 原型默认以手机竖屏 Web 为第一目标

## 当前要继续确认

- 页面结构是否已经覆盖最短闭环
- 文案草案是否足够支撑评审演示
- 终章与小游戏衔接是否还能再压缩层级
