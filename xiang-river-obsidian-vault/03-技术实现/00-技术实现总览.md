# 技术实现总览

这一组文档用于承接手机 Web 原型的技术选型、环境搭建和后续接入方向。  
它的目标不是写成长篇技术报告，而是让前期开发环境稳定、后期扩展方便。

## 当前技术方向

- 前端优先：Vite + React + TypeScript
- 样式方案：Sass + CSS Variables
- 状态管理：Zustand
- 测试与规范：Vitest、ESLint、Prettier
- 部署策略：手机 Web 优先，便于快速演示与景区部署验证

## 当前项目落地方向

- 主线中枢负责全程状态和节点切换
- 摄像头扫描与粒子引导先做轻量沉浸式模拟
- 后续可再逐步接入更真实的识别、定位和场景数据能力

## 当前要继续确认

- 目录结构是否足以承接主线页面扩展
- 哪些状态先做假数据，哪些状态直接对接真实接口
- UI 接口与节点接入规范是否需要再拆成更细的技术任务
