# 定位地图节点系统执行计划

## 来源

- 项目文档：`docs/superpowers/plans/2026-04-23-geolocated-map-node-system.md`
- 目标：新增基于浏览器定位的地图节点系统，节点任务可选择跳过，完成三处景物拍照后获得明信片，并在最终结算图中展示。

## 实现范围

- 新增 `src/features/map-nodes/` 纯逻辑模块，管理地图节点、距离计算、任务状态、拍照进度和明信片奖励。
- 在 `App.tsx` 接入浏览器 Geolocation API，并提供无法定位时的演示位置。
- 在主流程中显示区域地图和节点标记，用户进入节点后可以开始任务或跳过。
- 任务完成后生成明信片奖励，最终结算页展示明信片并提供分享入口。

## 执行步骤

1. 编写并验证地图节点纯逻辑测试。
2. 实现节点距离、最近可进入节点、跳过任务、拍照进度和明信片生成。
3. 编写并验证 App 交互测试。
4. 接入地图 UI、节点任务 UI、结算明信片 UI 与分享动作。
5. 补充移动端样式，运行 `npm test` 与 `npm run build`。
