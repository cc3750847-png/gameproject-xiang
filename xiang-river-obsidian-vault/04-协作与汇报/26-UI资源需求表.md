## 文档用途

这份文档面向项目中的统一 UI 负责人。  
目标是把后续需要产出的视觉资源按类别拆清楚，方便：

- 提前排期
- 判断哪些资源是全局共用
- 判断哪些资源是节点游戏专属
- 避免后期发现“页面有了，但缺资源可接”

这份文档不规定具体美术风格，而是规定资源类型与使用位置。

## 一、资源分类原则

建议把整个项目的 UI 资源分成 4 类：

1. 全局共用资源
2. 主线中枢专用资源
3. 节点游戏共用资源
4. 终章与传播资源

这样分的好处是：

- 全局资源可以最早开工
- 主线和节点资源可以并行
- 终章资源可以后置，不会卡前期原型

## 二、全局共用资源

这部分资源会在整个项目中反复出现，建议优先产出。

### 1. 色彩系统

需要定义：

- 主色
- 辅色
- 强调色
- 成功态颜色
- 解锁态颜色
- 错误 / 提示态颜色
- 透明遮罩层级

用途：

- 主线中枢
- 三个节点游戏
- 终章页
- 按钮、标签、弹层、奖励反馈

### 2. 字体与字重规则

需要定义：

- 标题字体规则
- 副标题字体规则
- 正文字体规则
- 标签字体规则
- 数值 / 进度字体规则

用途：

- 统一整个项目文字气质

### 3. 按钮资源

需要至少准备：

- 主按钮
- 次按钮
- 透明按钮
- 禁用态按钮
- 高亮态按钮
- 完成态按钮

用途：

- 主线推进
- 进入节点游戏
- 返回主线
- 海报生成
- 奖励领取

### 4. 状态标签资源

需要定义：

- 默认标签
- 进行中标签
- 接近中标签
- 已完成标签
- 已解锁标签
- 终章标签

### 5. 卡片与面板资源

需要准备：

- 信息卡片样式
- 奖励卡片样式
- 摘要卡片样式
- 弹层面板样式

## 三、主线中枢专用资源

这部分资源主要服务主线中枢。

### 1. 主线背景基底

需要准备：

- 主线页背景基底
- 不同阶段是否需要轻微变化版本

用途：

- 入口页
- 主线中枢页
- 节点跳转页

### 2. 扫描层资源

需要准备：

- 扫描框边角样式
- 扫描框边框样式
- 镜头引导提示层
- 扫描状态提示底板

用途：

- 摄像头扫一扫实景引导层

### 3. 粒子引导资源

需要准备：

- 远距离引导粒子母题
- 接近节点汇聚粒子
- 共鸣完成粒子
- 解锁下一节点粒子反馈

用途：

- 主线扫描
- 到点确认
- 共鸣完成反馈

### 4. 节点到达资源

需要准备：

- 节点标题样式
- 节点锁定/解锁图形
- 节点确认提示样式

用途：

- 主线进入节点前的确认页

## 四、节点游戏共用资源

虽然三个节点游戏玩法不同，但外层视觉可以共用一部分资源。

### 1. 节点游戏统一外壳

需要准备：

- 节点游戏顶部信息条
- 返回主线按钮样式
- 当前目标展示样式
- 完成页统一结构样式

### 2. 状态反馈资源

需要准备：

- 开始游戏提示样式
- 进行中反馈样式
- 成功反馈样式
- 奖励掉落 / 获得样式

### 3. 奖励展示资源

需要准备：

- 灵韵图标
- 章节碎片图标
- 节点成果标识

## 五、三个节点游戏专属资源

这部分由 UI 负责人与各节点游戏负责人协作决定。

### 游戏 A 专属

建议列清：

- 专属主视觉
- 专属核心交互图形
- 专属完成页元素

### 游戏 B 专属

建议列清：

- 专属主视觉
- 专属核心交互图形
- 专属完成页元素

### 游戏 C 专属

建议列清：

- 专属主视觉
- 专属核心交互图形
- 专属完成页元素

注意：

- 专属资源应只影响玩法区
- 外壳层和完成反馈层尽量复用统一系统

## 六、终章与传播资源

这部分资源会直接影响项目最后的“社交货币”表现。

### 1. 终章留痕页资源

需要准备：

- 终章标题样式
- 旅程摘要卡
- 留痕印记样式
- 终章背景或收束氛围图

### 2. 海报与分享资源

需要准备：

- 海报模板
- 标题版式
- 节点成果拼装位
- 玩家昵称或称号展示位
- 导出时的背景与边框逻辑

### 3. 奖励与权益资源

需要准备：

- 奖励入口卡
- 礼遇说明样式
- 奖励完成态样式

## 七、资源优先级建议

为了方便排期，建议把资源分成 3 个优先级。

### P1：必须最先做

- 色彩系统
- 字体系统
- 按钮体系
- 状态标签
- 主线背景基底
- 扫描框样式
- 粒子母题
- 节点游戏统一外壳

原因：

这些资源一旦没有，主线和节点游戏都没法形成统一视觉。

### P2：中期补齐

- 三个节点游戏的专属玩法区资源
- 奖励展示资源
- 解锁反馈资源
- 节点到达与完成页强化资源

原因：

这些资源会明显提升项目质感，但可以在骨架完成后继续补。

### P3：后期强化

- 终章海报模板
- 留痕页强化资源
- 传播导出样式
- 更高级的动画或粒子变体

原因：

这些资源更偏展示与传播，可以晚于主线和节点玩法。

## 八、建议的资源交付格式

为了方便后续实现，建议 UI 负责人输出时尽量统一格式。

### 静态资源

- PNG / WEBP：适合位图素材
- SVG：适合图标、标签、按钮边框、简洁图形

### 规范文档

- 色值表
- 字重与字号表
- 间距规则
- 状态使用说明

### 组件图

- 主按钮状态图
- 标签状态图
- 卡片状态图
- 扫描层结构图
- 完成页结构图

## 九、最小交付清单

如果现在要让 UI 负责人先开工，最少先做这些：

1. 全局色彩系统
2. 字体层级规则
3. 主按钮 / 次按钮 / 标签
4. 主线中枢卡片样式
5. 扫描框与粒子母题
6. 节点游戏统一外壳
7. 终章留痕基础模板

这 7 项出来后，项目就可以进入“结构和视觉同时推进”的状态。

## 十、一句话总结

UI 资源不是后期补图，而是整个主线中枢、三个节点游戏和终章留痕能否保持统一气质的基础设施。
