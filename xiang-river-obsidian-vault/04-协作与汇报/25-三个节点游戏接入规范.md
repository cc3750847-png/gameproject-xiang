## 文档用途

这份文档面向三个节点游戏的负责人。  
目标是明确：

- 每个节点游戏如何从主线进入
- 每个节点游戏内部至少要有哪些页面
- 游戏完成后如何返回主线
- 返回时必须交回哪些状态

它的作用是避免三个人各做各的，最后很难挂回主线。

## 一、节点游戏的统一定位

三个节点游戏虽然玩法不同，但在产品结构里都属于同一种角色：

- 它们不是独立 App
- 不是独立主线
- 而是主线中枢在特定节点唤起的子模块

所以每个节点游戏都必须满足两个前提：

1. 能被主线顺利接入
2. 完成后能顺利返回主线

## 二、统一接入原则

### 原则 1：从主线进入，不自行启动

节点游戏不应自己承担“怎么找到入口”的任务。  
入口永远由主线负责。

也就是说，节点游戏默认只处理：

- 进入后看到什么
- 怎么玩
- 玩完后怎么回去

### 原则 2：每个节点游戏都必须是闭环

每个节点游戏至少要具备：

1. 进入页 / 过渡页
2. 核心玩法页
3. 完成页
4. 返回主线动作

不能只有一个玩法页，没有完成状态和回传逻辑。

### 原则 3：返回主线时必须带状态

节点游戏结束后，不能只是“关掉页面”。  
必须把结果带回主线，让主线知道：

- 这一段是否完成
- 应不应该解锁下一节点
- 要不要把奖励记到终章里

## 三、主线 -> 节点游戏：进入接口

当主线到达某个节点并准备进入对应游戏时，建议统一传入以下信息。

### 必传字段

- `nodeId`
  当前节点唯一标识，用于区分是 A、B 还是 C

- `nodeTitle`
  当前节点标题，用于游戏进入页展示

- `chapterProgress`
  当前主线进度，例如第几段、是否已完成前置节点

- `entryText`
  从主线传来的过渡文案，保证进入感统一

- `rewardPreview`
  当前节点完成后预期获得的奖励或成果提示

### 可选字段

- `audioTheme`
  当前节点的音乐线索或主题标识

- `uiThemeVariant`
  该节点游戏允许使用的局部样式变体

- `unlockContext`
  当前节点在剧情中的意义说明

## 四、节点游戏内部最小页面结构

每个节点游戏最少应包括以下 3 个页面层。

### 1. 进入页 / 过渡页

作用：

- 承接从主线过来的过渡
- 告诉玩家接下来要做什么
- 建立节点游戏的局部目标

至少应包含：

- 节点标题
- 一句过渡文案
- 开始游戏按钮

### 2. 核心玩法页

作用：

- 承载该节点游戏的主要互动

至少应包含：

- 当前目标
- 核心玩法区域
- 退出方式或返回方式
- 当前状态反馈

注意：

核心玩法页可以因游戏而异，但顶部信息区和返回机制要保持统一。

### 3. 完成页

作用：

- 告诉玩家这一节点已经完成
- 展示奖励或结果
- 提供返回主线的入口

至少应包含：

- 完成标题
- 获得内容
- 下一步提示
- 返回主线按钮

## 五、节点游戏 -> 主线：退出接口

每个节点游戏完成后，至少要返回以下内容。

### 必回字段

- `nodeId`
  告诉主线是哪一个节点完成了

- `completed`
  当前节点是否完成

- `reward`
  当前节点奖励内容

- `unlockNext`
  是否解锁下一段主线

- `recordForFinale`
  是否要记入终章留痕

### 推荐附加字段

- `score`
  若玩法中有表现差异，可回传分数或评级

- `summaryText`
  节点完成后的摘要文字，便于主线展示

- `visualMark`
  终章海报或留痕页可用的节点成果标记

## 六、统一页面边界

为了让三个节点游戏负责人各自推进时不互相干扰，建议明确以下边界。

### 主线负责人负责

- 进入节点前的状态
- 节点跳转页
- 节点完成后的主线刷新
- 全局进度和解锁判断

### 节点游戏负责人负责

- 节点游戏内部流程
- 节点完成页
- 返回主线动作触发

### UI 负责人负责

- 统一外壳
- 顶部信息区
- 按钮样式
- 状态反馈样式
- 完成页结构语言

## 七、三个节点游戏的协作建议

虽然三个节点游戏玩法不同，但建议大家统一采用同样的开发骨架：

1. 进入页
2. 玩法页
3. 完成页
4. 返回主线

这样做有三个好处：

- 结构统一，方便 UI 统一
- 返回逻辑统一，方便主线接回
- 后续联调时更容易查问题

## 八、交付给节点游戏负责人的最小清单

如果你们马上要开始分工开发，每个节点游戏负责人至少需要拿到这些东西：

1. 自己对应的 `nodeId`
2. 节点标题与节点功能说明
3. 进入页所需文案
4. 完成后需要回传的字段
5. 统一 UI 外壳规则
6. 返回主线的方式

只有这 6 项明确了，节点游戏才能顺利并行推进。

## 九、一句话总结

三个节点游戏可以玩法不同，但接入方式必须统一：  
主线负责送进去，节点游戏负责完成闭环，完成后再把结果标准化地交回主线。
