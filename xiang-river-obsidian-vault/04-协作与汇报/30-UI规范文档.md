# UI 规范文档

来源：[[24-UI接口清单]]、[[26-UI资源需求表]]、项目文件 `docs/ui-design-spec.md`  
适用范围：入口、地图、节点、AR 引导、角色、终端、结算页，以及后续节点小游戏统一外壳。

## 设计原则

1. 页面先回答用户三个问题：我在哪、我能做什么、我能不能返回。
2. 一个页面只服务一个主动作，避免把地图、任务、奖励、接口状态都塞进同一块主卡片。
3. 视觉延续现有首页资产：暖纸色、橘棕、柔和江景氛围、宋体标题、清晰正文。
4. 主线 UI 负责导览与状态，节点小游戏 UI 负责玩法外壳。
5. 文化感来自字体、留白、色彩、图像与文案语气，不靠堆叠装饰。

## 基准画布

- 设计基准：390 x 844。
- 兼容范围：360 宽小屏、430 宽大屏、桌面预览。
- 安全边距：左右 16px，底部预留底部导航 100-116px。
- 普通页面最大宽度：420-440px。

## 色彩系统

| Token | 色值 | 用途 |
| --- | --- | --- |
| `paper-0` | `#fffaf4` | 页面最高亮底色、弹层正文底 |
| `paper-1` | `#f8efe6` | 默认页面底色 |
| `paper-2` | `#f1e2d1` | 次级分区、弱背景 |
| `river-ink` | `#5d3925` | 主标题、正文强文本 |
| `river-muted` | `rgba(93, 57, 37, 0.72)` | 正文弱文本、说明 |
| `orange-main` | `#b86f3e` | 主按钮、当前状态、关键强调 |
| `orange-deep` | `#8f4b22` | 深色强调、图标描边 |
| `gold-soft` | `#e0a06c` | 完成、奖励、高亮边缘 |
| `blue-river` | `#5f92a8` | 地图、水流、AR 辅助信号 |
| `green-life` | `#6f9962` | 可进入、成功、文化收集 |
| `red-alert` | `#b85a4a` | 错误、权限失败、危险提示 |

使用规则：

- 页面底色以暖纸色为主，AR 层可临时使用深色沉浸背景。
- 主按钮使用橘棕到柔金的轻渐变或实色。
- 状态标签使用低饱和底色，不做刺眼霓虹。
- 奖励和完成反馈使用金色高亮，但不能让全页变成单一金色。

## 字体与排版

| 角色 | 字体建议 | 用途 |
| --- | --- | --- |
| 文化标题 | Source Han Serif CN / Noto Serif SC / Songti SC | 页面标题、节点名、奖励标题 |
| 正文 | system-ui / Noto Sans SC / Microsoft YaHei | 说明、按钮、列表、状态 |
| 数字与状态 | system-ui | 距离、进度、计数、接口状态 |

| 层级 | 移动端字号 | 用途 |
| --- | --- | --- |
| H1 | 28-34px | 页面主标题 |
| H2 | 20-24px | 面板标题、节点标题 |
| H3 | 16-18px | 卡片标题 |
| Body | 14-16px | 正文说明 |
| Meta | 11-12px | 标签、状态、辅助信息 |
| Button | 15-16px | 主按钮、次按钮 |

规则：

- 移动端标题最多两行。
- 按钮文案最多 7 个汉字。
- 卡片正文最多 2-3 行。

## 通用组件规则

### 页面壳

页面壳包含背景、顶部信息区、页面主体和底部导航。除首页与 AR 层外，所有页面都使用同一内容宽度和底部安全区。

### 顶部信息区

包含：

- eyebrow：当前模块，如“区域地图”“节点详情”“玩家终端”。
- title：当前页面主标题。
- description：一句说明当前任务。
- statusTag：当前状态，如“演示定位”“可跳过”“已完成”。

### 按钮

| 类型 | 用途 | 视觉 |
| --- | --- | --- |
| Primary | 当前页面唯一主动作 | 橘棕实底或轻渐变，白字 |
| Secondary | 返回、跳过、查看说明 | 透明或浅纸底，橘棕文字 |
| Icon | 关闭、返回、调试、分享 | 44 x 44 点击热区 |
| Danger | 放弃、重置、权限失败处理 | 红色弱底，红棕文字 |

### 状态标签

固定标签池：启序、定位中、演示定位、真实定位、可进入、不可进入、可跳过、收集中、已完成、已跳过、接口异常、终章。

### 卡片与面板

卡片只用于独立对象：地图节点、任务目标、奖励、成就、明信片。不要用卡片套卡片。

通用结构：

- 顶部：标题 + 状态。
- 中部：1-2 行摘要。
- 底部：主操作或辅助信息。

### 底部导航

固定四项：主页、地图、角色、终端。AR 引导层打开时隐藏底部导航。

### AR HUD

必须包含：

- 顶部左侧：模式标签。
- 顶部或中心：方向提示。
- 顶部右侧：关闭按钮。
- 中央：扫描框或粒子汇聚区。
- 底部：一句当前状态说明。
- 调试控件默认收起。

状态：`seeking`、`aligning`、`locked`、`lost`。

## 页面状态覆盖

| 页面 | 必须覆盖状态 |
| --- | --- |
| 入口页 | 默认、继续旅程、设置/成就入口 |
| 地图页 | 未定位、定位中、演示定位、真实定位、无可进入节点、可进入节点 |
| 节点详情 | 可开始、不可进入、已跳过、已完成 |
| 节点任务 | 收集中、单项完成、全部完成、退出确认 |
| AR 引导 | seeking、aligning、locked、lost、权限失败 |
| 共鸣页 | 未按住、按住中、完成 |
| 角色页 | 默认头像、自定义头像、身份未选、身份已选 |
| 终端页 | 无成就、有成就、无明信片、有明信片、上传失败 |
| 结算页 | 无奖励、有明信片、可分享、分享失败 |
