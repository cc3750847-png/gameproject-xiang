# 协作与汇报总览

这一组文档负责解决“团队怎么分工、UI 怎么统一、节点游戏怎么接入、最后怎么对外讲清楚”。  
相比前面的策划与原型文档，这一组更偏协作边界和输出组织。

- 上级入口：[[00-首页]]

## 这组文档解决的核心问题

- 让主线中枢和三个节点游戏不是各做各的
- 让 UI 负责统一风格，而不是接管所有玩法逻辑
- 让原型、开发和美术之间有清楚的接口
- 让最终汇报材料能够直接复用前面的结构成果

## 当前要继续确认

- 分工版 IA 是否已经把主线、节点、终章拆到可执行粒度
- UI 接口是否足够标准化到能反向约束玩法
- 资源需求表是否还能继续压缩成更明确的优先级
